### Bugs found on the phone and fixed

| Bug | Seen | Fix |
|---|---|---|
| Guard read the keyboard instead of the app under a tap: the IME window's root spans the screen | Messaging: Send tapped without a question | `AgentService.liveNodeAt` picks the top window whose touchable region holds the point |
| Guard missed Google sign-in (`com.google.android.gms`) and Play Store installs | Contacts → "Add an account" → sign-in page (`ac41dea9`) | Both packages are sensitive; "sign in", "add account" and more labels |
| A run kept a dead accessibility-service instance after Android re-bound it | Permission prompt test: `RejectedExecutionException` | The loop looks the service up on every call (waits up to 5 s) |
| `open_app` failed on "Clock app", "Calender" | Action tests | Port of the research repo's `app_resolver` as a fallback |
| Typing appended to the field instead of typing at the cursor | Code review during the action tests | Insert at the selection, as a keyboard does |
| The time-of-use check held back taps when the focused field changed | Contacts run (`ac41dea9`) | Focus is compared for typing and Enter only |
| Logcat ring buffer dropped the first steps of long runs | Alarm run (`ac41dea9`) | Test setup: `logcat -G 16M`; run.json is the record |
